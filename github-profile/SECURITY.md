# Security Policy

## Reporting a vulnerability

**Do not report vulnerabilities in public issues, discussions or pull requests.**

1. **Primary channel — GitHub private vulnerability reporting.** Open the affected
   repository, go to its **Security** tab and click **Report a vulnerability**. The report
   is visible only to the maintainers.
   - VantaDB currently lives at [`ness-e/Vantadb`](https://github.com/ness-e/Vantadb);
     report there.
2. **Email**: `negent@negentmind.com` (available once negentmind.com is live).
3. If private reporting is not available in a repository, open a public issue that only
   asks for a private channel — without any vulnerability details.

Include: affected repository and version, description, steps to reproduce, and potential
impact.

## Process

- We acknowledge and respond within a reasonable time. There is no guaranteed response
  SLA.
- We confirm the issue, work on a fix and coordinate disclosure with the reporter.
- We publish a GitHub Security Advisory once a fix is available, crediting the reporter
  unless they prefer otherwise.

Thanks for helping keep Negent Mind projects safe.
