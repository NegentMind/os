# Política de Seguridad

## Reportar una vulnerabilidad

**No reportes vulnerabilidades en issues, discussions ni pull requests públicos.**

1. **Canal principal — reporte privado de vulnerabilidades de GitHub.** Abre el
   repositorio afectado, ve a su pestaña **Security** y pulsa **Report a vulnerability**.
   El reporte solo lo ven los maintainers.
   - VantaDB vive hoy en [`ness-e/Vantadb`](https://github.com/ness-e/Vantadb); repórtalo
     ahí.
2. **Correo**: `negent@negentmind.com` (disponible cuando negentmind.com esté activo).
3. Si un repositorio no tiene habilitado el reporte privado, abre un issue público que
   solo pida un canal privado — sin ningún detalle de la vulnerabilidad.

Incluye: repositorio y versión afectados, descripción, pasos para reproducir e impacto
potencial.

## Proceso

- Acusamos recibo y respondemos en un tiempo razonable. No hay un SLA de respuesta
  garantizado.
- Confirmamos el problema, trabajamos en una corrección y coordinamos la divulgación con
  quien lo reportó.
- Publicamos un GitHub Security Advisory cuando la corrección está disponible, dando
  crédito a quien lo reportó salvo que prefiera lo contrario.

Gracias por ayudar a mantener seguros los proyectos de Negent Mind.
