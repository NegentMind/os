# Code of Conduct

Negent Mind follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- **Expected behavior**: respect, inclusion, collaboration, good-faith review.
- **Unacceptable behavior**: harassment, discrimination, personal attacks, spam, sabotage.

## Reporting

Report conduct issues **privately only** — never in a public issue or discussion.

- **Email**: `negent@negentmind.com` (available once negentmind.com is live).
- Until then, use GitHub's **Report content** option on the comment, issue, pull request
  or user profile involved. Depending on the repository settings, the report goes to the
  repository maintainers or to GitHub; in both cases it is not public.

Reports are reviewed by the maintainers and handled confidentially.

## Enforcement

Maintainers may edit or remove content and restrict or ban participants, following the
enforcement guidelines of the Contributor Covenant.

**Full text**: [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
