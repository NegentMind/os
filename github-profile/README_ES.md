# Negent Mind — `.github`

Este es el repositorio especial `.github` de la organización
[NegentMind](https://github.com/NegentMind). Contiene dos cosas:

- **El perfil de la organización** — `profile/README.md` es lo que se muestra en
  [github.com/NegentMind](https://github.com/NegentMind). El `README.md` de la raíz (este
  archivo) no se muestra ahí.
- **Valores por defecto de toda la organización** — políticas de contribución, seguridad y
  conducta, y las plantillas de issues/PR. GitHub las aplica a cada repositorio de la
  organización que no defina las suyas.

El manifiesto, los principios, la gobernanza y el mapa de capacidades a largo plazo viven en
el **Public Handbook — se publica en diciembre de 2026**. <!-- HANDBOOK_URL: add when published -->
