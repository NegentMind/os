# Soporte

## Dónde preguntar

| Necesidad | Dónde |
|---|---|
| Reporte de bug | GitHub Issues del repositorio correspondiente (formulario de bug) |
| Solicitud de funcionalidad | GitHub Issues del repositorio correspondiente (formulario de funcionalidad) |
| Resultados de benchmark | GitHub Issues del repositorio correspondiente (formulario de benchmark) |
| Pregunta o ayuda de uso | [GitHub Discussions](https://github.com/NegentMind/.github/discussions) (categoría Q&A) |
| Vulnerabilidad de seguridad | Nunca en público — sigue [SECURITY_ES.md](./SECURITY_ES.md) |
| Problema de conducta | En privado — ver [CODE_OF_CONDUCT_ES.md](./CODE_OF_CONDUCT_ES.md) |

VantaDB vive hoy en [`ness-e/Vantadb`](https://github.com/ness-e/Vantadb); abre ahí los
issues de VantaDB.

Antes de abrir un issue, busca entre los existentes y lee el README y la documentación del
repositorio.

## Qué esperar

- **Async-first**: el soporte ocurre por escrito, en issues y discussions.
- **Tiempo de respuesta**: buscamos responder en un tiempo razonable. Esto es un
  laboratorio independiente; no hay SLA de soporte.
- **Sin canales privados** para preguntas generales: las respuestas públicas ayudan a la
  siguiente persona con el mismo problema.
