# Support

## Where to ask

| Need | Where |
|---|---|
| Bug report | GitHub Issues in the relevant repository (bug report form) |
| Feature request | GitHub Issues in the relevant repository (feature request form) |
| Benchmark results | GitHub Issues in the relevant repository (benchmark form) |
| Question or usage help | [GitHub Discussions](https://github.com/NegentMind/.github/discussions) (Q&A category) |
| Security vulnerability | Never in public — follow [SECURITY.md](./SECURITY.md) |
| Conduct issue | Privately — see [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) |

VantaDB currently lives at [`ness-e/Vantadb`](https://github.com/ness-e/Vantadb); open
VantaDB issues there.

Before opening an issue, search existing issues and read the repository's README and docs.

## What to expect

- **Async-first**: support happens in writing, in issues and discussions.
- **Response time**: we aim to respond within a reasonable time. This is an independent
  lab; there is no support SLA.
- **No private support channels** for general questions: public answers help the next
  person with the same problem.
