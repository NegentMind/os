# Código de Conducta

Negent Mind sigue el
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

En resumen:

- **Comportamiento esperado**: respeto, inclusión, colaboración, revisión de buena fe.
- **Comportamiento inaceptable**: acoso, discriminación, ataques personales, spam, sabotaje.

## Reportar

Reporta los problemas de conducta **solo en privado** — nunca en un issue o discussion
público.

- **Correo**: `negent@negentmind.com` (disponible cuando negentmind.com esté activo).
- Mientras tanto, usa la opción **Report content** de GitHub en el comentario, issue, pull
  request o perfil de usuario implicado. Según la configuración del repositorio, el reporte
  llega a los maintainers del repositorio o a GitHub; en ambos casos no es público.

Los maintainers revisan los reportes y los tratan de forma confidencial.

## Aplicación

Los maintainers pueden editar o eliminar contenido y restringir o expulsar participantes,
siguiendo las pautas de aplicación del Contributor Covenant.
