# revideo/ — render headless estilo Motion Canvas

MIT. Solo si se necesita render desatendido/CI o plantillas con variables para Shorts/TikToks.

## Para qué / cuándo no

- Sí: ads-a-escala, preview en browser con inputs dinámicos, `renderVideo()` por script.
- No: si Remotion/HyperFrames ya cubren el caso (preferirlos).

```sh
npm init @revideo@latest
```

Mínimo: `README.md` (motivo de retención), `package.json`, `src/project`, `output/` (ignorado).
