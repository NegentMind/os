# Brief: home `/` (Persuade)

## Alcance y modo

Superficie: home pública `/`. Modo Persuade: el visitante entiende qué es NegentMind, por qué importa y qué hacer en segundos.

## Audiencia, trabajo, acción, prueba

- Audiencia: desarrolladores y líderes técnicos que evalúan infraestructura para LLMs/agentes.
- Trabajo: decidir si esto merece su atención (GitHub, especificación, Public Handbook).
- Acción: ir a GitHub (star/fork) o seguir a mecanismo/prueba.
- Prueba: el mecanismo dramatizado en vivo (ruido→señal interactivo) + instrumentos con valores reales del repo; nada fabricado (sin testimonios, clientes ni benchmarks).

## Dirección fijada (dados 6-1-4, gana THE ROLL; v2: extracción literal de plantillas)

**Híbrido por zonas — Negent Mind primero, VantaDB como flagship.** Estructura implementada: hero (SilkHero — seda líquida WebGL portada verbatim de mondragon2: hero-card, loader real, wordmark `difference`, métricas) → 01 organización+problema (chrome `.sechead.split` portado de nice-squash) → 02 principio (Immersive — track 400vh, 46k puntos esfera→torusKnot→retícula por `externalProgress`, fases aria-live, tags paralaje) → 03 módulos (HolonGrid — grid `.feat` con instrumentos `HalftoneCanvas` + HUD de estado honesto ACTIVE/VISION) → 04 flagship (FlowBoard — track 400vh, stage-tabs, board blueprint con code/graph/metric/form panels + connectors dibujados; TerminalDemo nice-squash + counters reales) → 05 mecanismo+prueba (DescentSection: AsciiField, EntropyTrace, medición real) → 06 boundary (panel Pulse) → 07 landscape (tabla honesta) → 08 open source (OssCards — price-cards Bone/Void de mondragon2, "precio" = Apache-2.0) → marquee tipográfico (mondragon2, sólido/hueco) → 09 FAQ → footer con wordmark gigante (patrón ox). Interacción firma: scroll coreografiado con esculturas de puntos + nav flotante pill (mondragon2) con FlipText.
